# FitnessPro - Complete Fitness Application

A comprehensive cross-platform fitness app built with React Native, Firebase, and MongoDB.

## 📱 Features

- **User Profiles**: Age, weight, height, and fitness goals tracking
- **Workout Library**: Video tutorials with sets/reps tracking
- **Diet Tracker**: Calorie counter and daily meal planning
- **Wearable Integration**: Apple Watch and Fitbit syncing
- **Push Notifications**: Daily reminders and motivational quotes
- **Community Engagement**: Challenges and social features
- **Gamification**: Achievements and progress tracking

## 🛠 Tech Stack

### Frontend
- **Framework**: React Native / Flutter
- **UI Library**: React Native Paper / Material Design
- **State Management**: Redux / Provider
- **Navigation**: React Navigation

### Backend
- **Runtime**: Node.js / Express.js
- **Database**: MongoDB
- **Authentication**: Firebase Auth / OAuth 2.0
- **Cloud Services**: AWS / Google Cloud

### DevOps
- **Version Control**: Git
- **CI/CD**: GitHub Actions
- **Deployment**: App Store & Google Play Store

## 🚀 Getting Started

### Prerequisites
- Node.js (v14+)
- npm or yarn
- React Native CLI or Flutter SDK
- Firebase account
- MongoDB Atlas account

### Installation

```bash
# Clone repository
git clone https://github.com/awaiskhttak/makeit.git
cd makeit

# Install dependencies
npm install
# or
yarn install

# Setup environment variables
cp .env.example .env

# Run development server
npm start
```
